# Obscura UI 设计

## 已定决策

| 项 | 决定 |
|---|---|
| 形态 | C：平时低调小窗阅读；老板键默认“收进任务栏”——屏幕上消失，任务栏留伪装图标，从任务栏点开才全屏显示伪装界面 |
| 紧急避险 | 全部实现，每项均可在设置中单独开关 |
| 任务栏伪装 | 可选伪装为 VS Code / 记事本 / 文件夹等（图标 + 窗口标题），或完全不在任务栏显示 |
| 内容来源 | 第一阶段只做本地文件（txt / epub）；网络抓取待 UI 合格后再议 |
| 一屏内容 | 由窗口高度决定，自动显示整行；设置中可一键设为 1 / 3 / 5 / 8 / 12 行，之后可自由拖动 |
| 视觉风格 | 可切换（主题系统） |

## 界面清单

### 1. 阅读小窗（默认态）

- 无边框、可调透明度、可置顶；可贴边缩成一条
- 显示行数随窗口高度自适应（拖低即字幕条），余量上下平分
- 翻页：滚轮、方向键、可自定义快捷键
- 底部极简状态：进度百分比（可隐藏）

### 2. 伪装界面（老板键切换）

- 预设：VS Code、记事本、资源管理器
- 老板键动作可选：收进任务栏（默认）/ 立即显示伪装界面 / 完全隐藏；任务栏设为“不显示”时一律完全隐藏
- 无论处于哪一步，再按老板键都直接回到阅读小窗
- 伪装界面中的“代码”“文本”为静态假内容，不含小说文字

### 3. 紧急避险（设置中逐项开关）

- 老板键（全局快捷键）
- 鼠标移出窗口后自动降低透明度 / 模糊
- 任务栏：伪装图标与标题 / 隐藏
- Alt+Tab 中隐藏
- 失去焦点自动隐藏（可选）

### 4. 书架 / 文件打开

- 本地文件列表、阅读进度记忆
- 界面同样保持低调，避免出现“书架”字样（可显示为 “Workspace” / “Files”）

### 5. 设置

- 分组：外观（主题、字号、行数、透明度）/ 伪装 / 快捷键 / 文件

### 补充决策

| 项 | 决定 |
|---|---|
| 技术栈 | Tauri 2（体积小；WebView2 进程在 Win11 上常见，不显眼） |
| 主题 | 日志灰 / 终端 / 文档白 / 跟随系统 |
| 伪装界面 | 静态，不做交互 |
| 小窗默认位置 | 设置中可选：左下 / 右下 / 底边铺满 |
| 书架 | 可编辑：添加、重命名、分组、移除 |
| 任务栏图标 | 运行时从本机 VS Code / 记事本 / explorer.exe 提取，不分发第三方图标 |
| 目录 | epub 优先读 EPUB3 导航文档（nav），其次 EPUB2 的 toc.ncx；都没有时用每章第一个标题兜底。目录项定位到锚点，没有锚点则到章节开头。txt 没有目录 |
| 窗口位置 | 拖动阅读窗口后记住位置，启动和从书架 / 设置返回时回到该位置；记录的位置不在任何显示器工作区内时回到默认位置；改动“默认位置”设置会清除记录 |

## 第一版操作

- 拖动：按住窗口任意位置；边缘 6px 用于缩放
- 翻页：滚轮、↓ → 空格 PgDn / ↑ ← PgUp
- 老板键默认 Alt + `；可设为单个功能键（F1–F24、Pause、Scroll Lock、`、Insert 等）
- Esc：同老板键　Ctrl+O：文件　Ctrl+,：设置　Ctrl+T：目录（仅有目录的书；目录内 ↑↓ 选择、Home/End 首尾、Enter 跳转）
- 鼠标悬停时右上角出现工具栏（文件 / 目录 / 设置 / 隐藏；目录按钮仅在有目录的书上显示）
